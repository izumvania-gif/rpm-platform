## 📊 Структура MVP

### Модули P0 (обязательные для MVP):

- ✅ **Управление продуктами** - профили продуктов
- ✅ **Исследования** - репозиторий клиентских исследований
- ✅ **Сегменты** - сегментация клиентов

### Технологический стек:

- **Frontend:** Next.js 14, React 18, TailwindCSS, shadcn/ui
- **Backend:** Next.js API Routes, NextAuth.js
- **Database:** PostgreSQL 15+, Prisma ORM
- **Validation:** Zod, React Hook Form

### Milestone:

1. ✅ Инфраструктура готова
2. ✅ Аутентификация работает
3. ✅ Модуль "Продукты" работает
4. ✅ Модуль "Исследования" работает
5. ✅ Модуль "Сегменты" работает
6. ✅ MVP готов к использованию

## 🚀 Следующие шаги

MVP завершён, включая P1-модули (JTBD, Разговоры, Гипотезы). Актуальный план развития — [Growth Plan](./growth-plan.md):

1. **Фаза A:** Конкуренты, ресурсы продукта, Feature/RTB (ядро методологии)
2. **Фаза B:** Граф JTBD (иерархия + последовательность + визуальный канвас)
3. **Фаза C:** Матрица Сегменты×JTBD, дашборд пробелов, цитаты/выводы, поиск
4. **P2 модули:** AI Chat, Генерация гипотез, RAG
5. **P3 улучшения:** Мультиязычность, Интеграции, Экспорт
