# MVP Quick Start Checklist

Краткий чек-лист для быстрого старта разработки MVP платформы ECHO.

---

## Фаза 0: Подготовка инфраструктуры ⚙️

### Настройка окружения
- [ ] Установить Node.js 20+ и npm/yarn
- [ ] Установить PostgreSQL 15+
- [ ] Установить VS Code с расширениями (Prisma, ESLint, Prettier)
- [ ] Установить Git

### Инициализация проекта
- [ ] Создать Next.js проект: `npx create-next-app@latest rpm-platform --typescript --tailwind --app`
- [ ] Инициализировать Git: `git init`
- [ ] Создать `.gitignore` (включить `.env.local`, `node_modules`, `.next`)
- [ ] Первый коммит: `git commit -m "Initial commit: Next.js setup"`

### Установка зависимостей
```bash
# Основные зависимости
npm install @prisma/client next-auth @tanstack/react-query zod react-hook-form @hookform/resolvers date-fns lucide-react

# Dev зависимости
npm install -D prisma @types/node

# shadcn/ui
npx shadcn-ui@latest init
```

### Настройка Prisma
- [ ] Инициализировать Prisma: `npx prisma init`
- [ ] Настроить `DATABASE_URL` в `.env.local`
- [ ] Создать схему БД в `prisma/schema.prisma`
- [ ] Запустить миграцию: `npx prisma migrate dev --name init`
- [ ] Проверить в Prisma Studio: `npx prisma studio`

### Настройка NextAuth.js
- [ ] Создать `src/lib/auth.ts`
- [ ] Создать `src/app/api/auth/[...nextauth]/route.ts`
- [ ] Добавить `NEXTAUTH_SECRET` в `.env.local`
- [ ] Настроить провайдер Credentials

### Установка shadcn/ui компонентов
```bash
npx shadcn-ui@latest add button
npx shadcn-ui@latest add input
npx shadcn-ui@latest add form
npx shadcn-ui@latest add card
npx shadcn-ui@latest add dialog
npx shadcn-ui@latest add select
npx shadcn-ui@latest add textarea
npx shadcn-ui@latest add badge
npx shadcn-ui@latest add toast
npx shadcn-ui@latest add table
```

### Создание структуры проекта
- [ ] Создать `src/components/ui/` (shadcn/ui)
- [ ] Создать `src/components/forms/`
- [ ] Создать `src/components/layouts/`
- [ ] Создать `src/lib/prisma.ts`
- [ ] Создать `src/types/`

**Milestone 1 достигнут:** Инфраструктура готова ✅

## Полезные команды

```bash
# Разработка
npm run dev                    # Запуск dev сервера
npx prisma studio             # Открыть Prisma Studio
npx prisma migrate dev        # Создать миграцию
npx prisma generate           # Сгенерировать Prisma Client

# Деплой
npm run build                 # Сборка для production
npm run start                 # Запуск production сервера
npx prisma migrate deploy     # Применить миграции на production

# Утилиты
npm run lint                  # Проверка кода
npm run format                # Форматирование кода
```
