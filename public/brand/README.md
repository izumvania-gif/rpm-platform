# Фирменные ассеты Рутокен

## Происхождение

Векторы получены из `Logo Rutoken.ai`, переданного заказчиком. Файл `.ai`
оказался PDF-совместимым, поэтому контуры извлечены без потерь
(`pdftocairo -svg`), а не перерисованы — перерисовывать начертание логотипа
шрифтом брендбук прямо запрещает.

Два исходника не в репозитории намеренно: `.ai` весит 8,9 МБ, `.tif` — 93 КБ
в CMYK. Для веба нужны только эти SVG; исходники хранятся у дизайн-отдела.

## Файлы

| Файл                | Где применяется (брендбук, с. 1)           |
| ------------------- | ------------------------------------------ |
| `rutoken.svg`       | основной вариант — на белом и светлом фоне |
| `rutoken-white.svg` | на фирменном красном и на тёмном фоне      |

Обе версии — одни и те же 7 контуров, отличается только заливка.

## Два решения, принятые при подготовке

**Цвет взят из брендбука, а не из файла.** В `.ai` заливка лежала в CMYK и при
конверсии дала `#de1e32`. Официальное значение — `#dd2233` (C7 M97 Y88 K1,
Pantone 1795 C, с. 2 брендбука), оно и проставлено. Расхождение на глаз
незаметно, но источником правды должен быть брендбук.

**viewBox обрезан по контенту.** Артборд в `.ai` нёс ~50px пустого поля с
каждой стороны: логотип, вставленный как есть, выглядел бы мелким и смещённым
внутри своего слота. Отступы — забота вёрстки, а не файла.

## Чего здесь нет

**Шрифт Gilroy.** Брендбук показывает четыре начертания (Light / Regular /
SemiBold / Bold, с кириллицей), но самих файлов не содержит — Gilroy
лицензионный и в вебе не раздаётся. Пока лицензии нет, в проекте используется
**Manrope** (уже подключён через `next/font/google` как `--font-display`) —
ближайший геометрический гротеск. Montserrat и Poppins не подходят: другая
ширина, вертикальная плотность интерфейса поедет.
